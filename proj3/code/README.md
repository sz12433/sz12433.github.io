**How to Run Code:**
1. Running the main.ipynb file in the code folder should work!
2. I used ginput to handle accepting inputs for choosing points in images for parts A.2-A.4, and I believe pressing enter when you're finished choosing your points will close the input window
3. When it comes to choosing points, I documented in main.ipynb the points that I used, but in case you're interested in recreating my deployed images more explicity:
 - for the Grimes images = 3 points spanning the building roof + 1 pt at the first lamp at staircase base + the blue lamp
 - for inside Grimes = 5 points along the staircase (as seen in A.2)
 - Skywalk = center overlap of mountains + highest pt of mountain in im1 + the 3rd bar on the walkway left + right
